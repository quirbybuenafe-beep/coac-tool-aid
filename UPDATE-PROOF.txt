COAC Tool Aid cumulative update v28
RICH USER PORTAL / ADMIN-VIBE PARITY

This cumulative patch includes all v27 user portal + printable borrowing form changes, plus a full visual upgrade for student/professor accounts.

v28 USER UI CHANGES
- User portal now uses the same navy COAC top navigation language as the admin dashboard.
- Real COAC logo header instead of the flat user-only mark.
- Smooth 4-tab sliding navigation pill for Home / Inventory / Rooms & Keys / My Activity.
- Account block now mirrors the admin cloud-account presentation while keeping user permissions limited.
- Home now uses the same full-width COAC hero treatment as admin:
  * blue/navy gradient
  * grid background
  * gear motif
  * live date/time
  * Luntian side branding
  * COAC program showcase cards and logos
- Added personal identity strip in the hero showing program, TUPV ID, and access level.
- Added admin-style Personal Borrowing Overview zone.
- Added detailed activity stat cards for Active / Pending / Overdue / Completed Returns.
- Added richer Current Activity panel with type icons and status pills.
- Added Available Now panel for live tool-unit, room-key, and personal-record counts.
- Added My COAC Access profile panel with verified account identity details.
- Added Live Room Display using the same room-tile language as the admin dashboard while preserving borrower privacy.
- Inventory catalog cards are larger, deeper, and visually consistent with the admin dashboard.
- Tool category controls are now larger card-style tabs.
- Room & key cards are deeper and more polished while still hiding other borrowers' personal details.
- My Activity table now uses richer admin-style table spacing, headers, hover states, and print actions.
- Request modals were visually aligned to the richer COAC style.
- Responsive/mobile layouts updated for the richer user dashboard.

PERMISSIONS REMAIN LIMITED
- No user inventory editing/deletion.
- No maintenance administration.
- No other-borrower private data.
- No admin transaction deletion or global history access.
- User borrowing still uses request -> Tool Aid approval -> physical release.

PRINTING
- v27 COAC A4 Release / Return / Complete Record forms remain included.
- Default releasing officer remains Sir John Ray.
