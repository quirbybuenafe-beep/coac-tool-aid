COAC TOOL AID — D:\COAC INSTALLATION
=====================================

PERMANENT LOCATION
The complete project must be stored directly in:
D:\COAC

The folder should contain files such as:
D:\COAC\package.json
D:\COAC\START-WEBSITE.bat
D:\COAC\UPDATE-WEBSITE.bat
D:\COAC\app\
D:\COAC\tools\

FIRST INSTALL OR MOVING FROM AN OLD NESTED FOLDER
1. Download the newest complete COAC-Tool-Aid ZIP.
2. Leave the ZIP in your Windows Downloads folder.
3. Run UPDATE-WEBSITE.bat from the downloaded repair folder or your old project folder.
4. It installs the complete project directly into D:\COAC.
5. It starts D:\COAC\START-WEBSITE.bat when finished.

FUTURE UPDATES
1. Download the newest complete COAC-Tool-Aid ZIP from ChatGPT.
2. Leave it in Downloads. Do not extract it.
3. Close the old COAC Tool Aid server window.
4. Run D:\COAC\UPDATE-WEBSITE.bat.

The updater automatically:
- Uses D:\COAC as the permanent project folder.
- Skips repair-only ZIPs and finds the newest complete project ZIP.
- Makes a backup when an older installation already exists.
- Keeps node_modules when possible.
- Installs packages only when needed.
- Starts the website from D:\COAC after updating.

Your browser-saved borrowing records remain available because the website keeps using the same browser address and port.
