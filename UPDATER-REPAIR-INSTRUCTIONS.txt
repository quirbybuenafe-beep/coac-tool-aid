COAC TOOL AID — D:\COAC UPDATER REPAIR
======================================

This repaired updater always installs and launches COAC Tool Aid from:
D:\COAC

HOW TO USE
1. Download the complete COAC Tool Aid ZIP and leave it in Downloads.
2. Extract this repair ZIP anywhere.
3. Run UPDATE-WEBSITE.bat from the extracted repair folder.
4. The updater creates or updates D:\COAC automatically.
5. Afterward, always use D:\COAC\UPDATE-WEBSITE.bat for future updates.

You do not need to keep using the old nested folder:
D:\COAC\COAC-Tool-Aid-Latest

Delete that old folder only after confirming the website starts correctly from D:\COAC.
